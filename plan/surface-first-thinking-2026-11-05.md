# 从最基本的东西想：几何和颜色为什么要分开（2026-11-05，+++ 线，不进 CVPR）

Wenhao 11/05 06:57 的问题：训练/初始化/优化全可以改，甚至扔掉 Delaunay；mesh 本该擅长平滑曲面；颜色是不是该放到"连接"（边）上而不是顶点上，因为顶点色会晕开、细节只能靠堆小三角形。

## 1. 根因：一组顶点同时承担几何和颜色

- Gouraud（顶点色 + barycentric）是面内的低通：一个顶点的颜色是一个"点"，向整个 1-ring 晕开。要表现比面还小的颜色细节，唯一办法是在那里放更小的面。所以顶点密度跟着**颜色细节**走，不跟着形状走。
- 结果是几何自由度被当成外观容量用。证据：(a) P2（10/30）把训练好的 soup 当不透明表面渲染，room −2.0 / kitchen −3.6 dB——它的质量来自软混合，不是来自曲面；(b) codebook 实验：每顶点 SH 高度冗余（K4096 几乎无损），颜色是过剩的，几何才是瓶颈；(c) 11/05 正则实验：Laplacian/法线一旦真的起作用（b/c），PSNR 崩到 19 dB——因为每个顶点都在"画画"，平滑 = 掉色。
- 传统图形学的分解正好相反：几何 = 低频、流形、平滑（细分/法线）；外观 = 高频、放在纹理/法线贴图里。MeshSplatting 把两者揉在一个对象里，这是所有"不像 mesh"现象的共同来源。

## 2. Delaunay：它不是曲面重建

restricted Delaunay 的规则（effrdel 已核过）：对全部顶点做 3D Delaunay 四面体剖分，取内部面，保留"两个四面体外心连线穿过 soup"的面。它依赖的只是顶点云 + soup。一层顶点只要在深度上有一点抖动，这个点云在四面体剖分里就是一个有厚度的壳，壳内各个方向的面都可能被"穿过"而保留——所以出来的是 3D 复形里的一个 2-复形，不是 2-流形：non-manifold 边 48 %（lego v3）、瓦片状重叠、三角形尺度的大二面角。它从来不是 surface reconstruction。而且训练会很快离开它（方向 A：6000 步内 Delaunay-ness 丢光）。扔掉它没有损失；问题是用什么代替"把 soup 变成连续曲面"。

## 3. 颜色放到边上

- 有限元语言：边中点取色 + 面内线性 = Crouzeix–Raviart（非协调 P1）。性质：允许颜色跨边不连续（边中点处连续、顶点处不连续）；自由度 = 边数 ≈ 3V，是顶点色的 3 倍。
- 它只改颜色插值，不改几何；"表面在边上变化"这个直觉对几何（折痕在边上）成立，对颜色不成立（纹理边界和网格边没有关系，除非网格边被训练去对齐纹理边）。
- 它的"合法形式"是 per-face texture（mesh colours / Ptex）：每面按分辨率 r 取样，边和顶点上的样本在相邻面共享所以连续；r=2 时样本正好在顶点 + 边中点，就包含了"边上存色"。所以不要单独做边色，直接做 per-face texture。
- 真正的收益不是表达力（1 px/面时任何插值都等价于线性，P2 已证），而是**解耦**：颜色分辨率由 r 决定，顶点只需要描述形状 → 顶点变少、面变大、曲面变光滑，Laplacian/法线正则这时候才有空间起作用而不掉色。

## 4. "从最基本的东西"出发的链

soup 的长处是软混合给全图梯度（不透明光栅只有轮廓梯度，从零开始训不动）。所以：soup 只当 **finder**（几何初值 + 可见性），交付物是**流形曲面 + 面上纹理**。

最小链（lego，约 1 GPU-h，= 10/30 推迟的 P2b）：
1. 用训练好的 soup（现成 checkpoint）在训练视角渲染 expected depth → TSDF 融合（Open3D，体素 ~1/512 场景）→ marching cubes → 流形网格；quadric 简化到 5 万 / 10 万 / 20 万面；轻度 Laplacian 平滑。CPU 几分钟。
2. 在同一个曲面上用不透明可微光栅（nvdiffrast，diag/texture_refit_v1.py 已有骨架）各拟合一次外观，等字节比较 test PSNR：
   (i) 顶点 SH（Gouraud，对照）；(ii) 细分 1-2 次后的顶点 SH（= "堆小三角形"）；(iii) per-face texture，r = 2 / 4 / 8，SH 阶 1-3。
3. 若 (iii) 在等字节下 ≥ (ii)，且在 5-10 万面的网格上离 soup 的 33.5 dB 不超过 ~1.5 dB（NeRF2Mesh 32.1、MobileNeRF 34.2 是这一类的现成标尺），再加第 4 步：顶点位置 + 纹理联合精修，Laplacian 正则（这回不会掉色），顺便看平滑后能不能回收一部分。

通过/失败的读法：
- (iii) ≈ (ii) 且都远低于 soup：细节靠的是几何层叠（多层半透明）而不是颜色分辨率 → 单层不透明曲面本身是上限，答案是 4.3 的"曲面 + alpha 卡片"混合。
- (iii) > (ii) 且接近 soup：你的直觉成立，颜色该离开顶点，几何可以粗而滑；这是 +++ 的主线。
- TSDF 曲面本身很差（深度不一致）：先用 2DGS/NeuS 类方法给曲面初值，soup 只提供颜色。

## 5. 风险

- 从软混合 soup 取 expected depth 可能噪，薄结构（lego 的横杆）会断；可用 median depth 或只取 opacity 累积 > 0.5 的首面。
- 无界场景（Mip-360）背景需要远壳（+++ 4.2 已写）；先在 Blender 单物体上验证分解本身。
- 不透明光栅只在轮廓给几何梯度，第 4 步的几何精修幅度要小、依赖好的初值。
