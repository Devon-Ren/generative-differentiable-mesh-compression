# F1 + F2：3D 记忆媒介的数学可行性（2026-11-21，新项目线）

上游文档：`plan/memory-medium-2026-11-21.md`。本文件只回答"数学上行不行、代价多大"，不涉及从照片训练（那是 F3）。

## F1 理论

### 设定
- 场景：不透明的实体 S ⊂ ℝ³（静态，无雾、无玻璃、无半透明）。
- 观看区域 V：用户回看记忆时可能站的位置（拍摄轨迹附近）。
- 自由空间 Ω：ℝ³ \ S 中包含 V 的那个连通分量。放到射影空间 ℙ³ 里看（加上无穷远平面），Ω 的闭包是紧的。
- 媒介：∂Ω 加上它上面的出射辐射 L(x, ω)。

### 命题 1：边界决定内部的所有视图（复变直觉的精确版本）
对任意 p ∈ Ω 和方向 ω，从 p 出发的射线在碰到 S 之前一直留在 Ω 里，所以第一个交点 x 一定在 ∂Ω 上。于是看到的颜色 I(p, ω) = L(x, −ω)。
- 结论：Ω 内所有视角的所有画面，由（∂Ω，L）唯一决定。体积表示存 5D，这里只需要 4D；对接近漫反射的表面，约等于 2D 的一张图。
- 与全纯函数的不同：没有刚性。∂Ω 上没被看到的部分，L 和几何都不被数据决定。
- 实际只需要 ∂Ω 中从 V 可见的那一部分。

### 命题 2：闭合与无穷远
∂Ω 是紧闭集，所以从 Ω 内任何位置看出去，每条射线都打在 ∂Ω 上：没有洞。射线 p + tω 在 t → ∞ 时收敛到无穷远点 [ω : 0]；天空 = ∂Ω ∩ 无穷远平面，用齐次坐标 w = 0 的顶点可以直接光栅化。

### 命题 3：亏格 0 对渲染足够（隐藏手术）
∂Ω 的亏格 g 可以很大（每根连接地面和拱顶的柱子都贡献一个"把手"）。但：
- 对实体一侧有压缩圆盘的把手（柱子、桌腿、拱：实体是"柄体"的一切情形），沿一个**位于实体内部**的圆盘 D 切开，两侧各封一个盖子，得到亏格 g − 1 的闭曲面。
- 盖子在实体内部，从 Ω 里只能透过一条零宽度的切缝看到它，所以**从任何 p ∈ Ω 渲染出的画面除一条测度为零的曲线外完全不变**。
- 重复 g 次得到亏格 0；多个连通分量用零宽度的细管连成一个。再由单值化定理，结果共形等价于 S²，即存在映射 X: S² → ℙ³。
- 例外：实体一侧不可压缩的把手（例如在实体里钻了一条**打结**的隧道），只能在自由空间一侧切，会留下一张看得见的膜。真实场景里几乎不存在，记为已知限制。
- 推论：你最初"从一个球开始"的设想在表达能力上是**完备的**（对不透明静态场景），不需要支持任意拓扑。

### 命题 4：没看到的地方怎么补（最小承诺原则）
∂Ω 上没被看到的区域 U，其边界 Γ 落在已观测部分上。
- 几何：存在张在 Γ 上的极小曲面（Plateau 问题，Douglas–Radó 定理），即肥皂膜。
- 颜色：Γ 上颜色已知时，调和延拓存在且唯一（Dirichlet 问题），是所有补全里"最平滑"的那个。
- 这是一个先验，不是真值；要更好的补全，需要生成模型，而它也作用在同一个球面域上。

### 命题 5：一张照片的情形
若 Ω 关于中心 c 是星形的，∂Ω = {c + ω / ρ(ω)}，ρ: S² → [0, ∞) 是单值函数（ρ = 0 为无穷远）：就是一张 360° 逆深度全景。非星形时 ρ 是多值的，映射必须"折叠"。

### 数学给不了的
(i) 代价：多少字节达到多少误差；(ii) 从照片能否恢复（反问题）；(iii) 半透明、薄结构。前两项由 F2 / F3 用实验回答，第三项是表示范围之外的已知限制。

## F2 实验：表示能力和代价（只用 CPU，不用照片，用真值 mesh）

代码和结果 json：`memory-medium/f2/`（ray casting 渲染 + embree；真值 = Khronos glTF 示例库的 Sponza（室内中庭，带纹理，顶部敞开 = 天空在无穷远）和 DamagedHelmet（物体））。

评估方式：在观看区域里随机放测试相机（离中心 r 米，每个 r 12 张，160×120，2×2 超采样），把表示渲染出来和真值比：
- **深度错误率**：逆深度相对误差 > 5 % 的像素比例（几何对不对的主指标）；
- **洞**：真值有表面、表示却没有的像素；
- PSNR：仅供参考。颜色是逐顶点存的（不是纹理），PSNR 主要受颜色采样密度限制，不反映几何。

### 结果 1：闭合由构造保证
所有变体、所有视角，洞 = 0.00 %（物体模式在轮廓擦边处 ≤ 0.3 %，是亚像素擦边）。

### 结果 2：径向球（一张照片的阶段）表达力和代价
室内 Sponza，以 c 为中心的径向球（二十面体第 L 层）：

| 层 L（顶点数） | r = 0 | r = 0.5 m | r = 1 m | r = 2 m | r = 4 m |
|---|---|---|---|---|---|
| 6（4 万） | 6.9 % | 8.5 % | 8.0 % | 15.6 % | 30.9 % |
| 7（16 万） | 3.8 % | 5.8 % | 6.0 % | 11.8 % | 26.8 % |
| 8（66 万） | 2.1 % | 4.5 % | 5.1 % | 10.3 % | 24.9 % |

（数字 = 深度错误率。）物体 DamagedHelmet（相机在外，径向收缩包裹）：L8 深度错误率 0.7 %。

代价（第 8 层，66 万顶点，逆深度和颜色按层级预测 + 量化 + 熵估计）：

| 量化（ρ / 颜色） | 几何 | 颜色 | 合计 | r = 0 深度错误 |
|---|---|---|---|---|
| 2e-4 / 2 级 | 0.37 MB | 0.64 MB | 1.01 MB | 2.4 % |
| 4e-3 / 8 级 | 0.08 MB | 0.28 MB | 0.36 MB | 2.4 % |

几何只需要 **1–4.5 bit/顶点**，连接关系 0 bit（由细分层级隐含）。作为对比：ByteMesh 的位置约 25 bit/顶点，连接约 29 bit/顶点。
读法：一张照片的"3D 记忆"在数学上和字节上都没有问题：几百 KB，完全闭合。它的有效范围是拍摄点周围约 0.5–1 m（在柱廊这种遮挡很重的场景里）；离开得更远，误差来自被遮挡区域（命题 5：需要折叠）。

### 结果 3：离开中心，需要折叠。两种构造的结果
**(a) 局部逐射线拟合（失败）**：从径向球出发，让多视角射线把三角形推到真值深度，并细分长边。曲面一直是球（Euler 数 = 2），但不收敛：训练视角深度错误率 10.8 % → 14 %，4 m 区域发散到 84 %。说明**大幅折叠不能靠局部梯度长出来**，和 MODL 的"不能改亏格"是同一个问题。

**(b) 先雕刻自由空间 Ω，再取边界（拓扑对了，分辨率不够）**：把观看区域里 160 个位置看到的空间标为自由（8 cm 体素），marching cubes 取 ∂Ω。

| 区域 | 小碎片数 | 主曲面亏格 | r = 0 | r = 1 | r = 2 | r = 4 |
|---|---|---|---|---|---|---|
| 2 m | 131 | 335 | 12.9 % | 22.9 % | 21.7 % | 30.2 % |
| 4 m | 77 | 240 | 16.8 % | 25.7 % | 26.8 % | 27.7 % |

（第一版是逐射线采样雕刻，远处射线间距大于体素，留下几千个没雕掉的碎块，亏格算出来上千：是我的实现错误，已改为逐体素投影，上表是修正后的数字。）
- 好的一面：主曲面水密、闭合，真实的拓扑被自动处理了。Sponza 的自由空间边界确实有两三百个把手（柱子、栏杆、植物叶片），小碎片是叶片之类的薄东西。
- 不好的一面：均匀 8 cm 体素对近处和掠射地面太粗，深度错误率在所有半径上都不如径向球。径向球的分辨率天然按"从观看点看过去的角度"分配，体素是均匀的。

### F2 结论
1. **闭合、无穷远、亏格 0、代价**：都没有数学障碍。径向阶段 0.4–1 MB 就够，几何 1–4.5 bit/顶点。
2. **真正的难点被定位了**：离开拍摄点需要折叠和拓扑，这一步**不能靠在网格上做局部优化**（3a），而要靠**对内部 Ω 的全局构造**（3b）。
3. 这和"边界决定内部"的对偶刚好吻合：**交付的是边界（球面上的图），构造的是内部（自由空间）**。3b 拓扑对、分辨率差；径向球分辨率对、拓扑差。下一步要把两者统一成一件事：在"按观看角度分配分辨率"的坐标里描述 Ω，而不是均匀体素。例如以拍摄点为中心的（方向，逆距离）坐标，正好就是命题 2 的射影坐标。
4. 没验证的：(i) 隐藏手术在 Sponza 的两三百个把手上是否都能在实体一侧完成（命题 3 的前提），需要计算；(ii) 一切都用的是真值几何，从照片能否构造 Ω 是 F3。
