# F1 + F2：3D 记忆媒介的数学可行性（2026-11-21，新项目线）

上游文档：`plan/memory-medium-2026-11-21.md`。本文件只回答"数学上行不行、代价多大"，不涉及从照片训练（那是 F3）。

## F1 理论

### 设定
- 场景：不透明的实体 S ⊂ ℝ³（静态，无雾、无玻璃、无半透明）。
- 观看区域 V：用户回看记忆时可能站的位置（拍摄轨迹附近）。
- 自由空间 Ω：ℝ³ \ S 中包含 V 的那个连通分量。放到射影空间 ℙ³ 里看（加上无穷远平面），Ω 的闭包是紧的。
- 媒介：∂Ω 加上它上面的出射辐射 L(x, ω)。

### 命题 1：边界决定内部的所有视图（复变直觉的精确版本）
对任意 p ∈ Ω 和方向 ω，从 p 出发的射线在碰到 S 之前一直留在 Ω 里，所以第一个交点 x 一定在 ∂Ω 上。于是看到的颜色 I(p, ω) = L(x, −ω)。
- 结论：Ω 内所有视角的所有画面，由（∂Ω，L）唯一决定。体积表示存 5D，这里只需要 4D；对接近漫反射的表面，约等于 2D 的一张图。
- 与全纯函数的不同：没有刚性。∂Ω 上没被看到的部分，L 和几何都不被数据决定。
- 实际只需要 ∂Ω 中从 V 可见的那一部分。

### 命题 2：闭合与无穷远
∂Ω 是紧闭集，所以从 Ω 内任何位置看出去，每条射线都打在 ∂Ω 上：没有洞。射线 p + tω 在 t → ∞ 时收敛到无穷远点 [ω : 0]；天空 = ∂Ω ∩ 无穷远平面，用齐次坐标 w = 0 的顶点可以直接光栅化。

### 命题 3：亏格 0 对渲染足够（隐藏手术）
∂Ω 的亏格 g 可以很大（每根连接地面和拱顶的柱子都贡献一个"把手"）。但：
- 对实体一侧有压缩圆盘的把手（柱子、桌腿、拱：实体是"柄体"的一切情形），沿一个**位于实体内部**的圆盘 D 切开，两侧各封一个盖子，得到亏格 g − 1 的闭曲面。
- 盖子在实体内部，从 Ω 里只能透过一条零宽度的切缝看到它，所以**从任何 p ∈ Ω 渲染出的画面除一条测度为零的曲线外完全不变**。
- 重复 g 次得到亏格 0；多个连通分量用零宽度的细管连成一个。再由单值化定理，结果共形等价于 S²，即存在映射 X: S² → ℙ³。
- 例外：实体一侧不可压缩的把手（例如在实体里钻了一条**打结**的隧道），只能在自由空间一侧切，会留下一张看得见的膜。真实场景里几乎不存在，记为已知限制。
- 推论：你最初"从一个球开始"的设想在表达能力上是**完备的**（对不透明静态场景），不需要支持任意拓扑。

### 命题 4：没看到的地方怎么补（最小承诺原则）
∂Ω 上没被看到的区域 U，其边界 Γ 落在已观测部分上。
- 几何：存在张在 Γ 上的极小曲面（Plateau 问题，Douglas–Radó 定理），即肥皂膜。
- 颜色：Γ 上颜色已知时，调和延拓存在且唯一（Dirichlet 问题），是所有补全里"最平滑"的那个。
- 这是一个先验，不是真值；要更好的补全，需要生成模型，而它也作用在同一个球面域上。

### 命题 5：一张照片的情形
若 Ω 关于中心 c 是星形的，∂Ω = {c + ω / ρ(ω)}，ρ: S² → [0, ∞) 是单值函数（ρ = 0 为无穷远）：就是一张 360° 逆深度全景。非星形时 ρ 是多值的，映射必须"折叠"。

### 数学给不了的
(i) 代价：多少字节达到多少误差；(ii) 从照片能否恢复（反问题）；(iii) 半透明、薄结构。前两项由 F2 / F3 用实验回答，第三项是表示范围之外的已知限制。
