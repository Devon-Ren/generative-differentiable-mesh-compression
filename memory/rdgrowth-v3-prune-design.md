C = matched-count control. v2's `--dd_mode importance` IGNORES lambda (grows add_percentage every interval = dense original), so it is not a ranking control. train_rd_v2m.py = v2 + `--split_schedule <rd_log.jsonl>`: per-interval split count capped at the reference lambda run's `n_split` at the same iteration, selection = upstream importance sampling -> differs from the lambda run only in WHICH triangles split. B = phase-B lambda-prune. rd_prune.py: select_collapses(vertices, faces, face_err, lam, mu, BPV, B_face, max_frac): score s_uv = (D_u + D_v - D_uv)/dR_uv with D_v = residual mass of faces touching v (acc.distortion(), same per-view per-Mpx units as split), dR_uv = (BPV - 2 B_face) + n_faces(uv) * B_face (interior 2 faces = BPV, boundary BPV-2, non-manifold more); candidates s < lam*mu; independent set by repeated locally-minimal edge matching (float64 + seeded random jitter; index-ordered jitter crawled one row per pass), cap max_frac*V per round cheapest first, foldover_filter rejects collapses flipping a surviving face. collapse_edges(triangles, pairs): midpoint into slot u, dc/rest averaged, opacity averaged in activation space, Adam exp_avg/exp_avg_sq averaged, v->u remap, degenerate + duplicate faces dropped, per-face trackers sliced, then upstream _prune_vertices(mask). train_rd_v3.py = v2m + `--prune_iters 12000 14000 16000 18000 --prune_mu 1.0 --prune_max_frac 0.15 --bytes_per_face 2.0` (accumulator reset at Delaunay, keeps accumulating until the last round; prune block before optimizer.step; event 'prune' logs n_cand/cand_frac, score q10/50/90 vs thr, pairs/cap/flip-rejected/passes, faces_removed_share sel/cand/all, V/T before/after).
